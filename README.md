# fume-hood
physical hardware project to make a fume hood for soldering and other things
what will be needed for build:
  soldering iron (possibly optional but highly recomended)
  screwdriver (possibly optional if you already have a motor)
  3d printer (could possibly make a thing like the 3d print but without a 3d printer)
  clear flat material that optionally can be shaped (optional)
as you may be able to see this is highly configurable
